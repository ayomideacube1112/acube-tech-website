# A'Cube Tech V3 — Professional website + guided AI assistant

This version keeps the WhatsApp-first pricing model. It adds a guided on-site assistant that routes visitors to services and prepares WhatsApp requests. It is a client-side assistant, not a live AI API, so it does not pretend to have live admission dates, prices, stock, or portal status.

Deploy by dragging this folder into your existing Netlify site's Deploys dropzone. Netlify supports updating drag-and-drop sites this way.
